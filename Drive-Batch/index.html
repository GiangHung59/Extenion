Bạn muốn tải những file nào?

Chọn các file đọc được bên trong hoặc mở Drive để tải cả thư mục.

Không dùng API nên không thể đảm bảo đọc đủ thư mục lớn. Tải cả thư mục: mở Drive, chọn menu của thư mục → Tải xuống; Google sẽ tạo ZIP. Thư mục con cần quét riêng.

Quét tab chỉ đọc các mục đang hiển thị. Cuộn trong Drive rồi quét lại để bổ sung; danh sách tự bỏ trùng.
