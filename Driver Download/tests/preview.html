Bạn muốn tải những file nào?

Chọn các file đọc được bên trong hoặc mở Drive để tải cả thư mục.

Không dùng API nên không thể đảm bảo đọc đủ thư mục lớn. Tải cả thư mục: mở Drive, chọn menu của thư mục → Tải xuống; Google sẽ tạo ZIP. Thư mục con cần quét riêng.

Quét tab chỉ đọc các mục đang hiển thị. Cuộn trong Drive rồi quét lại để bổ sung; danh sách tự bỏ trùng.

NƠI LƯU FILE

Chọn một lần, lưu cả đợt

Tiện ích nhớ lựa chọn này cho các lần tải sau. Bạn có thể đổi nơi lưu ở popup bất cứ lúc nào.

Để trống để lưu ngay vào thư mục gốc. Thư mục con chưa có sẽ được tạo khi tải file đầu tiên.

Thư mục tải xuống Chrome
Muốn chọn một thư mục khác trên máy: bấm Đổi thư mục gốc → Thay đổi trong cài đặt Chrome. Thay đổi này áp dụng cho mọi lượt tải xuống của Chrome. Sau đó mở lại tiện ích để tiếp tục.

Đổi thư mục con chỉ áp dụng cho đợt tải mới; các file đã xếp hàng vẫn dùng nơi lưu của đợt đó.
